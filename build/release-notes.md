## MDView 2 — split-view Markdown editor and viewer

Raw Markdown on the left, a live formatted preview on the right that scrolls with it. Open many files in tabs; your open tabs come back next time.

- **Editor / Split / Preview** views, draggable divider, synced scrolling
- **Tabs**, multi-file open, drag-and-drop, Save All, session restore
- **Sidebar** with open files and a clickable heading outline
- Formatting toolbar, find and replace, light and dark themes
- Prose wraps to the window; code blocks and diagrams keep their shape
- Tick task checkboxes in the preview; links to other `.md` files open in a tab

2.0.1 publishes releases directly, so downloads appear here without a manual step. No app changes from 2.0.0.

### Install (Windows 10/11, 64-bit)

1. Download **`MDView-Setup-2.0.1.exe`** below.
2. Run it. If Windows shows *"Windows protected your PC"*, click **More info → Run anyway** (the app is not code-signed).
3. Approve the administrator prompt, keep the default folder, and finish.
4. To open `.md` files with MDView by double-clicking: right-click any `.md` file → **Open with → Choose another app → MDView**, tick **Always**.

No admin rights? Download **`MDView-2.0.1-portable.exe`** instead and just run it (it does not register `.md` files).

Upgrading: run the newer installer over the old one; settings are kept.
